📝 Analyst Note

Investigated an RDP brute-force alert originating from an external source. Multiple failed authentication attempts were observed against different/non-existing accounts.


The source IP returned 8/91 detections in VirusTotal, indicating suspicious reputation.


Further investigation identified a successful RDP authentication following the failed attempts. The sequence is consistent with potential brute-force activity resulting in successful authentication.

🚨 Final Verdict

TRUE POSITIVE

The alert was classified as a True Positive based on the combination of repeated failed authentication, external source activity, suspicious IP reputation, and subsequent successful RDP authentication.

🛡️ Recommended Response

  • Investigate the successful RDP session.
  • Review activity performed after authentication.
  • Identify the authenticated account.
  • Review related Windows security events.
  • Investigate or block the source IP according to SOC policy.
  • Reset credentials if compromise is confirmed.
